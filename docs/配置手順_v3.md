## 4. 会場 PC（2 台以上）

- Chrome のショートカットを v2 §8 に **`--autoplay-policy=no-user-gesture-required` を足して**作る: `chrome.exe --kiosk --kiosk-printing --autoplay-policy=no-user-gesture-required https://coco529.sakura.ne.jp/dev/sj2026-gunshi/`（`?debug=1` は付けない）。これで最初の操作を待たずに声が出る。付けられない場合も、最初に画面をクリックすれば声が出る（Ctrl+Alt+K や Esc だけでは解錠されないことがあるが、その後のクリックで解錠される）。
- スピーカーの音量を会場で合わせる。軍師の声の音量・消音・隠すは係パネル（Ctrl+Alt+K）で PC ごとに設定でき、PC に保存される。
- 声を一切出さない運用にする場合は URL に `?gunshi=novoice`（吹き出しと擬似口パクのみ）、軍師ごと出さない場合は `?gunshi=off`。
